# restaurant_menu

A simple static HTML website for displaying a restaurant menu and allowing customers to place orders.

## Description

This project is a single-page HTML application that showcases a restaurant's menu items with images, descriptions, and prices. It includes an interactive order form where users can select quantities of items, choose drinks, and add special requests.

## Features

- **Menu Display**: Showcases three menu items (Caesar Salad, Alfredo Pasta, Margherita Pizza) with images, descriptions, and prices.
- **Order Form**: Allows users to select quantities for each menu item, choose a drink option, and enter special requests.
- **Responsive Design**: Uses CSS for a clean, centered layout with a warm color scheme.
- **Navigation**: Simple navigation links to jump to the menu or order form sections.

## How to Use

1. Open `restaurant_menu.html` in any modern web browser.
2. Browse the menu section to view available items.
3. Scroll to the "Place Your Order" section.
4. Enter quantities for desired items (use number inputs).
5. Select a drink option.
6. Add any special requests in the textarea.
7. Click "Go To Checkout" to submit the form (note: this is a static page, so submission is for demonstration only).
